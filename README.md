# مشروع مُنجَز: قائمة مهام عربية

## فكرة المشروع
مُنجَز تطبيق قائمة مهام بسيط يساعد المستخدم على تنظيم يومه. صُمم بواجهة عربية من اليمين إلى اليسار، ويعمل على الهاتف والكمبيوتر. كُتبت الواجهة والتنسيقات والمنطق في ملفات منفصلة باستخدام HTML وCSS وJavaScript فقط.

## محتويات المجلد
- `index.html`: هيكل الصفحة ومكوناتها، مثل بطاقات الإحصاءات، نموذج الإضافة، أزرار التصفية والقائمة.
- `style.css`: الألوان والخطوط وتوزيع العناصر والحركات والتصميم المتجاوب.
- `script.js`: إضافة المهام وإكمالها وحذفها وتصفيتها وحساب التقدم وحفظ البيانات.

## طريقة التشغيل
1. فك ضغط المجلد إن وصل إليك كملف مضغوط.
2. افتح `index.html` في متصفح حديث مثل Chrome أو Edge.
3. اكتب اسم المهمة واضغط «أضف مهمة» أو مفتاح Enter.
4. اضغط المربع بجانب المهمة لتحديدها مكتملة. استخدم أزرار التصفية لعرض الكل أو المهام قيد التنفيذ أو المكتملة.

لا يحتاج المشروع إلى تثبيت مكتبات أو إعداد خادم. خط IBM Plex Sans Arabic يُحمّل من Google Fonts عند توفر الإنترنت، وتظهر خطوط بديلة عند عدم توفره.

## شرح الفكرة البرمجية

### 1. HTML: بناء الصفحة
يحدد `index.html` العناصر التي تظهر للمستخدم. الخاصية `lang="ar"` تعرّف لغة الصفحة، و`dir="rtl"` تجعل اتجاهها من اليمين إلى اليسار. كل رقم أو قائمة لها `id` كي يصل إليها JavaScript ويحدّثها. يستدعي الملف `style.css` للتنسيق و`script.js` للتفاعل.

### 2. CSS: الشكل والاستجابة للشاشات
تحتوي بداية `style.css` على متغيرات مثل `--purple` و`--ink`؛ تعديل قيمة واحدة يغيّر اللون في مواضع متعددة. القواعد الأساسية تنظم البطاقات والأزرار، بينما `@media` يغيّر ترتيب المساحة إلى عمود واحد على الشاشات الصغيرة وعمودين على الشاشات الواسعة. ويوفر `:focus-within` مؤشراً مرئياً عند الكتابة في حقل المهمة.

### 3. JavaScript: البيانات والسلوك
تمثل كل مهمة كائنًا يحتوي على `id` فريد، و`text` للنص، و`completed` لحالة الإنجاز، و`createdAt` لتاريخ الإضافة. تحفظ المصفوفة `tasks` هذه الكائنات.

- `loadTasks()` تقرأ البيانات عند فتح الصفحة وتتعامل مع البيانات غير الصالحة.
- `saveTasks()` تحول القائمة إلى نص JSON وتحفظها في `localStorage`.
- `render()` ترسم المهام الموافقة للتصفية وتحدّث الأعداد وشريط التقدم ورسالة الإنجاز.
- `addTask()` و`toggleTask()` و`deleteTask()` تغيّر بيانات القائمة، ثم تحفظها وتعيد عرضها.
- مستمعو الأحداث (`addEventListener`) يشغّلون هذه الوظائف عند إضافة مهمة أو تغيير التصفية أو مسح المكتملة.
- تُنشأ نصوص المهام باستخدام `textContent` حتى تعرض كما كتبها المستخدم ولا تُعامل كتعليمات HTML.

### ما هي localStorage؟
هي مساحة تخزين صغيرة داخل المتصفح. تظل المهام عند تحديث الصفحة أو إغلاقها وفتحها مرة أخرى على المتصفح نفسه. البيانات محفوظة محليًا في جهاز المستخدم، ولا تُرسل إلى خادم. مسح بيانات المتصفح قد يمسح هذه القائمة.

## نص مقترح للعرض أمام الدكتور
«مشروعي اسمه مُنجَز، وهو تطبيق قائمة مهام عربي مبني باستخدام HTML وCSS وJavaScript. قسمت العمل إلى ثلاثة ملفات: HTML لبناء الصفحة، وCSS للتصميم المتجاوب، وJavaScript للتفاعل. يستطيع المستخدم إضافة المهام وإكمالها وحذفها وتصفيتها. حسبت نسبة الإنجاز تلقائيًا، واستخدمت localStorage حتى تبقى المهام بعد تحديث الصفحة. اخترت إنشاء نص المهمة باستخدام textContent لعرضه بأمان. لا يحتاج التطبيق إلى خادم أو مكتبات إضافية.»

## تجربة عملية سريعة أثناء العرض
1. أضف ثلاث مهام مختلفة.
2. أكمل مهمة واحدة، ولاحظ تغير العدد والنسبة.
3. اعرض المهام المكتملة ثم المهام قيد التنفيذ.
4. حدّث الصفحة لإظهار أن القائمة محفوظة.
5. امسح المهام المكتملة.

## أسئلة متوقعة
**لماذا فصلت الملفات؟** لتسهيل قراءة كل جزء وتعديله: الهيكل منفصل عن الشكل والسلوك.

**كيف تبقى المهام بعد إعادة التحميل؟** يحفظ JavaScript مصفوفة المهام في `localStorage` بصيغة JSON، ثم يقرأها عند فتح الصفحة.

**هل يعمل التطبيق على كل الأجهزة؟** يتكيف تصميم CSS مع عرض الشاشة، ويعمل في المتصفحات الحديثة. التخزين خاص بكل متصفح وجهاز.

**كيف تحسب نسبة الإنجاز؟** عدد المهام المكتملة مقسوم على إجمالي المهام، ثم يُضرب في 100 ويُقرب إلى عدد صحيح. إذا لم توجد مهام تكون النسبة صفرًا.

**كيف أطور المشروع لاحقًا؟** يمكن إضافة أولوية وتاريخ استحقاق، أو تصنيفات، أو تعديل المهمة بعد إضافتها.
